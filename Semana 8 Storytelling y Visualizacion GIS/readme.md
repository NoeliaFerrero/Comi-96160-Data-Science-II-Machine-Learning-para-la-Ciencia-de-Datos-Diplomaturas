### 🧘 Zen del Storytelling con Datos

1. **A veces, menos es más.** Si todo es importante, nada lo es.
2. **No cuentes todo lo que encontraste; cuenta lo que importa.** El análisis completo puede quedar detrás de escena.
3. **Un gráfico no es storytelling.** Es storytelling cuando ayuda a entender *qué pasó, por qué importa y qué hacemos ahora*.
4. **Los datos no toman decisiones: las personas sí.** El storytelling conecta evidencia con acción.
5. **Contexto antes que conclusión.** Sin un “¿respecto de qué?”, un número es apenas un número con buena autoestima.
6. **No adornes: explica.** Cada color, gráfico o dato debe tener un propósito.
7. **La historia debe llevar a algún lugar.** Si no cambia una decisión, una pregunta o una acción, probablemente sobra.
8. **Primero el mensaje, después el gráfico.** No busques qué decir a partir del gráfico que ya hiciste.
9. **Simplificar no es ocultar.** Es quitar ruido para hacer visible lo importante.
10. **El protagonista no es el dashboard.** Es la decisión que el dashboard ayuda a tomar.


🧘 Los 10 mandamientos del Storytelling para no torturar a tu audiencia
A veces, menos es más. 47 gráficos no son una historia: son una amenaza.
No cuentes todo lo que encontraste. Tu EDA fue interesante para vos. Para el CEO… probablemente no.
Un gráfico no cuenta una historia por sí solo. Necesita contexto, mensaje y propósito.
Primero la pregunta, después el gráfico. No al revés. Nunca al revés. 😌
Si todo destaca, nada destaca. El arcoíris no es una estrategia visual.
Los datos aportan evidencia; vos construís el argumento.
Una buena historia termina en una decisión. “Mirá qué interesante” no es una recomendación.
Simplificar no es mentir. Es sacar ruido para que aparezca la señal.
El protagonista no es el dashboard. Es la persona que tiene que decidir algo.
Si necesitás 20 minutos para explicar el gráfico, probablemente el gráfico necesite terapia.
