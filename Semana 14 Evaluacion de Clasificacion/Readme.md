# Exactitud vs. Precisión

* **Exactitud:** ¿Qué tan cerca estoy del valor real?
* **Precisión:** ¿Qué tan agrupadas o consistentes son mis mediciones?

---

## Ejemplo: «Me quiero pesar para bajar de peso»

Imaginemos que el peso real de una persona, medido con una balanza de referencia confiable, es de **70 kg**. Comparamos cuatro balanzas:

| Balanza | Mediciones (kg) | ¿Qué observamos? |
| :--- | :--- | :--- |
| **A** | 70,1 · 69,9 · 70,0 | Precisa y exacta |
| **B** | 75,0 · 75,1 · 74,9 | Precisa, pero inexacta |
| **C** | 68,0 · 72,0 · 70,0 | Menos precisa, pero exacta en promedio |
| **D** | 65,0 · 73,0 · 77,0 | Ni precisa ni exacta |
